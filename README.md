# Startup Failure Predictor

A machine learning-based web application that predicts whether a startup is likely to succeed or fail based on business-related factors.

## 🚀 Live Demo

https://startupfailurepredictor.onrender.com

## 📌 Project Overview

The Startup Failure Predictor uses machine learning to analyze startup business factors and predict the possible outcome of a startup.

The application provides a simple web interface where users can enter startup-related information and receive a prediction.

## ✨ Features

- Startup success/failure prediction
- Machine learning-based prediction
- Simple and user-friendly web interface
- Flask backend
- Random Forest classification model
- Live deployment using Render

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- HTML
- CSS
- JavaScript
- Git & GitHub
- Render

## 📊 Input Factors

The model uses business-related factors such as:

- Funding
- Number of employees
- Founder experience
- Revenue
- Expenses
- Market size
- Customer growth
